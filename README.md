# CampusFlow

## About
CampusFlow is a Python student planner for college students.
It will help users organize college work and activities in one place.

## Planned Features
- Add assignments with class names and due dates.
- Set low, medium, or high priorities.
- View upcoming assignments and activities.
- Add campus activities with dates and times.
- Mark tasks complete.
- Save tasks for later use.
